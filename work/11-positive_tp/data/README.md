# Data description

The electricity data used in this chapter are obtained from Ember.

## Yearly electricity data

Source: Ember Yearly Electricity Data  
https://ember-energy.org/data/yearly-electricity-data/

The original dataset contains electricity generation data for substantially more countries, years, technologies and variables than required for this chapter. It was reduced to the observations relevant to Denmark, Germany, Poland, Spain and the United Kingdom.
The analysis uses wind and solar electricity generation shares, aggregate fossil shares and, for the United Kingdom benchmark, coal shares. The analysis period is 2000 to 2025.

## Monthly electricity data

Source: Ember Monthly Electricity Data  
https://ember-energy.org/data/monthly-electricity-data/

The original monthly dataset was reduced to the observations relevant to Germany, Poland and Spain.
The analysis uses monthly aggregate fossil electricity shares from January 2015 to December 2025 for the early-warning analysis.
