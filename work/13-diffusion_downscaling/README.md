# Diffusion-Based Statistical Downscaling of Alpine Climate Fields

Conditional diffusion model for statistical downscaling of daily near-surface temperature
(`tas`) and precipitation (`pr`) over the Alpine domain, following the EDM formulation of
Karras et al. (2022) and the downscaling setup of Watt & Mansfield (2024)
([ClimateDiffuse](https://github.com/robbiewatt1/ClimateDiffuse)). Trained on CERRA
reanalysis pairs (coarsened input → native-resolution target), then applied to MBCn
bias-corrected regional climate model output across four Global Warming Level periods.

**Research questions**

1. **Calibration** — are the model's high-resolution ensembles calibrated on held-out
   reanalysis data?
2. **Signal preservation** — does the learned mapping preserve the driving projection's
   climate change signal at unseen warming levels?

Since training targets reanalysis, not a convection-permitting model, no high-resolution
truth exists in the projection period — RQ2 is assessed as *signal stability* (downscaled
Δ vs. coarse Δ), not future skill.

---

## Method

- **Target**: the *residual* between the fine CERRA field and the bilinearly interpolated
  coarse field — the network never has to reproduce the large-scale field it is given.
- **Conditioning**: 6 channels — 2 noisy residual (`tas`, `pr`), 2 normalized coarse, 2
  static (land–sea mask `lsm`, orography `orog`). Day-of-year/hour enter via the EDM
  label embedding (`label_dim=2`).
- **Architecture**: `EDMPrecond((256, 320), 6, 2, label_dim=2, model_channels=64)`
  (`code/wm2024model.py`), an EDM-preconditioned U-Net.
- **Sampler**: 2nd-order Heun, 40 steps, `sigma_min=0.002`, `sigma_max=80`, `rho=7`,
  churn `S_churn=40` (`code/sampling.py`).
- **Ensembles**: generated by re-seeding the sampler for a fixed coarse input.

**Domain**: 42.2–51.4 °N, 2.4–18.9 °E, resampled to a 256 × 320 grid (≈ 3.4 km spacing).

## Installation

Requires Python 3.11–3.14 and a CUDA GPU for training (CPU works for inference but is slow).

```bash
uv sync
```

Run every command below from the repository root
(`data/`, `model/`, `plots/` paths are relative to the current directory). On Windows,
`torch` is pulled from the `cu128` wheel index (`pyproject.toml`).

## Expected data layout

`data/`, `model/`, `plots/` and `cache/` are gitignored.

```
data/
├── reanalysis/
│   ├── tas/CERRA_tas_daily_<YYYY>_<MM>.nc

model/<epoch>.pt                     # checkpoints
```

## Pipeline

**1 — Data preparation**

```bash
uv run python code/data_prep/coarsen_cerra.py          # CERRA → MBCn 0.11° grid, 25×25 window mean
uv run python code/data_prep/aggregate_mbcn_daily.py   # 3-hourly → daily (tas mean, pr sum)
```

**2 — Training**

```bash
uv run python code/training/TrainDiffusion.py
```

20 epochs, batch size 4 × accumulation 8, AdamW `1e-4` + `ReduceLROnPlateau`, mixed
precision, EMA decay 0.999. Splits: train 2000–2016, val 2017–2018, test 2019–2020.
Sample grids → `plots/training/`; losses logged to W&B (`climate-diffusion-downscaling`).
`data/norm_stats.npz` is written as a side effect; regenerate standalone with
`uv run python code/training/ComputeNormStats.py`.

**3 — RQ1: calibration on held-out reanalysis**

```bash
uv run python code/evaluation/CalibrationPeriodAssessment.py --checkpoint ./model/20.pt --stride 7 --n-clim 12 --cache-dir ./cache
```

Ensemble CRPS vs. bilinear baseline, rank histograms, spread–skill, power spectra, a map
of where the model's correction diverges from the baseline.
→ `plots/calibration/`.

**4 — RQ2: behaviour across warming levels**

```bash
uv run python code/evaluation/ProjectionPeriodAssessment.py --checkpoint ./model/20.pt --stride 12 --n-clim 4 --cache-dir ./cache
```

Example-date comparison; Δ maps per GWL period vs. PRESENT; period means as percent
change (`--show-native-coarse` for the native reference); distribution consistency;
hottest/wettest day on record. GWL periods: `PRESENT` 2001–2020, `GWL2` 2021–2040,
`GWL3` 2041–2060, `GWL4` 2061–2080. → `plots/projection/`. Predictions cache under
`--cache-dir`, so re-plotting doesn't re-run the sampler.

**5 — Single dates, ensembles**

```bash
uv run python code/inference/Inference.py cerra 2019-01-05
uv run python code/inference/Inference.py mbcn  2010-07-15
uv run python code/inference/HottestWettestDayInference.py --checkpoint ./model/20.pt
```

## Output locations

Figures land under `plots/` (see `code/paths.py`): `training/`, `calibration/`,
`projection/` (with `2_delta/` per-period panels), `inference/`.
