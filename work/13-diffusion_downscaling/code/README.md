# Diffusion-Based Statistical Downscaling of Alpine Climate Fields

Conditional diffusion model for statistical downscaling of daily near-surface temperature
(`tas`) and precipitation (`pr`) over the Alpine domain, following the EDM formulation of
Karras et al. (2022) and the downscaling setup of Watt & Mansfield (2024)
([ClimateDiffuse](https://github.com/robbiewatt1/ClimateDiffuse)).

The model is trained on CERRA reanalysis pairs (coarsened input → native-resolution target)
and then applied to MBCn bias-corrected regional climate model output across four Global
Warming Level periods.

**Research questions**

1. **Calibration** — does the model produce calibrated high-resolution ensembles for
   temperature and precipitation on held-out reanalysis data?
2. **Signal preservation** — is the climate change signal of the driving projection
   preserved when the learned mapping is applied to unseen warming levels?

Because training targets reanalysis rather than a convection-permitting model, no
high-resolution truth exists in the projection period. RQ2 is therefore assessed as
*signal stability* (downscaled Δ vs. coarse Δ), not as future skill.

---

## Method

- **Target**: the *residual* between the fine CERRA field and the bilinearly interpolated
  coarse field — the network never has to reproduce the large-scale field it is given.
- **Conditioning**: 6 input channels — 2 noisy residual channels (`tas`, `pr`), 2
  normalized coarse channels, and 2 static channels (land–sea mask `lsm`, orography
  `orog`). Day-of-year and hour enter through the EDM label embedding (`label_dim=2`).
- **Architecture**: `EDMPrecond((256, 320), 6, 2, label_dim=2, model_channels=64)`
  (`src/downscaling/wm2024model.py`), an EDM-preconditioned U-Net.
- **Sampler**: 2nd-order Heun, 40 steps, `sigma_min=0.002`, `sigma_max=80`, `rho=7`,
  stochastic churn `S_churn=40` (`src/downscaling/sampling.py`).
- **Ensembles**: generated by re-seeding the sampler for a fixed coarse input.

**Domain**: 42.2–51.4 °N, 2.4–18.9 °E, resampled to a 256 × 320 grid (≈ 3.4 km spacing).

## Installation

Requires Python 3.11–3.14 and a CUDA GPU for training (CPU works for inference but is slow).

```bash
uv sync                 # or: pip install -e .
```

Every command below is written as `uv run python -m ...`, so no venv needs to be activated
first. With an activated venv, plain `python -m ...` is equivalent.

If any command fails with `ModuleNotFoundError: No module named 'downscaling'`, the
editable install has gone stale — the `.pth` file in `site-packages` stops being applied.
Re-run:

```bash
uv sync --reinstall-package climate-seminar-diffusion-downscaling
```

Worth checking before a long evaluation run. `PYTHONPATH=src` also works as a fallback.

On Windows, `torch` is pulled from the `cu128` wheel index (configured in `pyproject.toml`).

## Pipeline

**1 — Data preparation**

```bash
uv run python -m downscaling.data_prep.coarsen_cerra          # CERRA → MBCn 0.11° grid, 25×25 window mean
uv run python -m downscaling.data_prep.aggregate_mbcn_daily   # 3-hourly → daily (tas mean, pr sum)
```

**2 — Training**

```bash
uv run python -m downscaling.training.TrainDiffusion
```

Defaults: 20 epochs, batch size 4 with gradient accumulation ×8 (effective 32), AdamW at
`1e-4` with `ReduceLROnPlateau`, mixed precision, EMA decay 0.999. Splits are
train 2000–2016, validation 2017–2018, test 2019–2020. Per-epoch sample grids go to
`plots/training/`; losses and figures are logged to Weights & Biases
(project `climate-diffusion-downscaling`).

Normalization statistics are written to `data/norm_stats.npz` as a side effect of
training; regenerate them standalone with `uv run python -m downscaling.training.ComputeNormStats`.

Note that the validation denoising loss rewards conditional-mean collapse and is therefore
not a valid stopping criterion for generative quality. Compare checkpoints on
ensemble-level diagnostics instead — re-run `CalibrationPeriodAssessment` with different
`--checkpoint` values and compare CRPS and the spread–skill relationship.

**3 — RQ1: calibration on held-out reanalysis**

```bash
uv run python -m downscaling.evaluation.CalibrationPeriodAssessment \
    --checkpoint ./model/20.pt --stride 7 --n-clim 4 --cache-dir ./cache
```

Produces ensemble CRPS against the bilinear-baseline CRPS, rank histograms, the
spread–skill relationship, radially averaged power spectra, a spatial map of where the
model's correction systematically adds to or diverges from the coarse baseline
(averaged over the whole held-out period), and coarse/downscaled/truth distribution
comparisons. Figures land in `plots/calibration/`.

**4 — RQ2: behaviour across warming levels**

```bash
uv run python -m downscaling.evaluation.ProjectionPeriodAssessment \
    --checkpoint ./model/20.pt --stride 15 --cache-dir ./cache
```

- an example-date plot: one historical MBCn date shown as native coarse | bilinear
  interpolated | downscaled;
- climate change signal — Δ maps of the downscaled field, the interpolated coarse field,
  and their difference, for each projection period against the PRESENT baseline;
- period means as percent change against the reference field (bilinearly interpolated,
  or native with `--show-native-coarse`) — precipitation as a plain ratio, temperature
  against its Kelvin-equivalent reference so a period whose mean sits near 0 °C doesn't
  distort the percentage;
- distribution consistency — marginals, quantile shifts, and ensemble spread by period;
- the hottest and wettest day on record in the MBCn projection data, run through the
  model and shown as native | interpolated | downscaled (same comparison
  `HottestWettestDayInference.py` runs standalone, see below — kept here too since this
  assessment's model/grid setup is already loaded).

GWL periods are non-overlapping 20-year blocks: `PRESENT` 2001–2020, `GWL2` 2021–2040,
`GWL3` 2041–2060, `GWL4` 2061–2080.
Figures land in `plots/projection/`.

Both assessments cache ensemble predictions under `--cache-dir`, so re-plotting does not
re-run the sampler.

**5 — Single dates, ensembles, diagnostics**

```bash
uv run python -m downscaling.inference.Inference cerra 2019-01-05
uv run python -m downscaling.inference.Inference mbcn  2010-07-15
uv run python -m downscaling.inference.HottestWettestDayInference --checkpoint ./model/20.pt
uv run python -m plot_diffusion_process.diag_ensemble_spread mbcn 1998-07-15 --n 20
uv run python -m plot_diffusion_process.diag_forward_process  2019-01-05
uv run python -m plot_diffusion_process.diag_denoiser_estimate cerra 2019-01-05 --seed 42
uv run python -m plot_diffusion_process.diag_denoiser_estimate mbcn  2010-07-15 --seed 42
```

## Output locations

Every figure is written under `plots/` (see `src/downscaling/paths.py`):
`training/`, `calibration/`, `projection/` (with `2_delta/` per-period panels),
`inference/`, and `diagnostics/`.

## Known limitations

- The coarse field is regridded to the fine grid through a Delaunay/barycentric step
  followed by bilinear interpolation. Neither step conserves mass, so part of the apparent
  precipitation surplus relative to the coarse input originates in the regridding chain
  rather than in the model.
- Training seeds are not fixed, so training variance is unquantified.
- No variance-stabilizing transform is applied to precipitation; the model is trained
  directly on untransformed residuals.
